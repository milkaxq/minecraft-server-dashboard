# A dashboard for players

Authenticated pages use the homepage's dark forest palette, original world artwork and bright green primary actions. Inputs, status/error messages, confirmations, mobile navigation and portalled custom dropdowns receive matching colors.

The dashboard leads with a world banner and permission-aware shortcuts to game rules, player invitations, addons and backups. Shortcuts appear only for an activated, connected server and permitted actions. They navigate to existing controls; they never start Minecraft or change settings automatically. The main world selection is independent of list search/history filters.

A single world has a larger horizontal card on desktop and a stacked card on mobile. Hosting totals remain collapsed. Notifications and private-beta access guidance are still available. Existing management behavior is retained.

Verification covers authenticated navigation, dropdown keyboard selection, permissions, mobile/laptop screenshots, public-domain links, and existing server workflows. Deployment does not change live game settings or processes.
